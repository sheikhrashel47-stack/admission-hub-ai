## ১. সৎ মূল্যায়ন: আজ কোথায় দাঁড়িয়ে আছি?

## ২. Phase A — "অবশ্যই ChatGPT-এর মতো লাগবে" (২–৩ সপ্তাহ, $0)

### A1. ভিশন + PDF/Office পার্সিং — সবচেয়ে বড় উইন (এক সপ্তাহ)
Gemini-র ফ্রি টিয়ার **নেটিভ PDF/ইমেজ ইনপুট** দেয়। আমাদের কাছে Gemini key আগেই আছে।
- 📄 `+` → PDF/DOCX/XLSX/PPT/ছবি → Gemini-তে পাঠাও → বিশ্লেষণ (সবগুলোতে কাজ করবে, txt-এর পাশাপাশি)
- 📷 ক্যামেরা/গ্যালারি → ছবি বোঝা ("এই টেবিলটা কপি করো", "সিলেবাসের ছবি থেকে প্ল্যান বানাও")
- প্রিভিউ থাম্বনেল + "দস্তাবেজ বিশ্লেষণ" টাস্ক কার্ড (UI রেডি আছে)
- **খরচ:** $0 (Gemini ফ্রি টিয়ার — দৈনিক লিমিট আছে, তাই fallback chain-এ txt-পথ থাকবে)

### A2. উত্তরের মান + বিশ্বাসযোগ্যতা (এক সপ্তাহ)
- সিস্টেম প্রম্পট v2: গঠন, গভীরতা, বাংলা টোন, "জানলেই বলো" — গ্রেডেড
- সাইটেশন ইনলাইন লিংকে ক্লিকযোগ্য [1] → সোর্স শিটে স্ক্রল
- প্রতিটি উত্তরের পরে **ফলো-আপ প্রশ্ন সাজেশন** (ChatGPT-স্টাইল, মডেল থেকে — fake নয়)
- **থাম্বস 👍/👎** → ইউজেজ লগে জমা → কোন মডেল/মোডে সমস্যা সেটা ড্যাশবোর্ডে
- লম্বা চ্যাটের **অটো-সংক্ষেপণ**: ২৪ মেসেজের বেশি হলে আগের অংশ সারাংশে বদলে কনটেক্সট বাঁচবে (KV-তে ক্যাশ)

### A3. চ্যাট ইন্টারঅ্যাকশন পলিশ (এক সপ্তাহ)
- ইনলাইন মেসেজ এডিট (ইতিমধ্যে আছে) + এডিট-পর-অটো-রিজেনারেট
- উত্তর-ভেরিয়েন্ট (প্রথম উত্তরের নিচে "আরেকটা ভার্সন") — Regenerate-এর আলাদা ডিজাইন
- কোড ব্লকে **কপি/রান-অন-মডেল** বাটন (রান = Phase B-র মডেল)
- টোকেন/সেকেন্ড কাউন্টার, রেট-লিমিট হলে নরম মেসেজ
- **লাইভ প্রিভিউ পোর্টে** পুরোটা টেস্ট করা যাবে

### A4. স্মৃতি v2 — আসল মেমরি (এক সপ্তাহ)
- "আমার সম্পর্কে" নোট → **স্বয়ংক্রিয় শেখা**: গুরুত্বপূর্ণ তথ্য (নাম, লক্ষ্য, প্রজেক্ট) উত্তর থেকে বের করে স্মৃতিতে যোগ (মডেল-এক্সট্রাক্ট, ইউজার নিশ্চিতকরণসহ)
- প্রতি-চ্যাট নয়, **ক্রস-চ্যাট** কনটেক্সট: "গত সপ্তাহের ফাইলটা মনে আছে?"
- KV JSON-এই চলবে — নতুন ইনফ্রা লাগবে না

## ৩. Phase B — আসল Agent (UI কার্ড রেডি আছে — ইঞ্জিন বানাই) (৩–৫ সপ্তাহ, $0)

**নীতি:** Agent = মডেল যে নিজে সিদ্ধান্ত নিয়ে টুল চালায়, স্টেপ-কার্ডে দেখায়, শেষে ফল দেয়। মিথ্যে "Agent মোড" নয়।

### B1. Research Agent (সবচেয়ে সহজ, সবচেয়ে দরকারি)
সিস্টেম: প্রশ্ন → মডেল ৩–৫টি সাব-প্রশ্ন বানায় → প্রতিটি Tavily সার্চ → রিড → একত্রে সাইটেশনসহ রিপোর্ট → স্টেপ-কার্ডে লাইভ আপডেট। আজকের SEARCHING/READING/ANALYZING কার্ডগুলোই আসল স্টেপ হবে।

### B2. File Agent
আপলোড করা ১টি বা একাধিক ফাইল: মডেল নিজে ঠিক করে কোন ফাইলে কী খুঁজবে, প্রতিটির বিশ্লেষণ একত্রে "সব ফাইলের তুলনা" রিপোর্ট।

### B3. Code Agent (E2B / WebContainers — ফ্রি টিয়ার)
- কোড রান: E2B (ফ্রি স্যান্ডবক্স) বা StackBlitz WebContainers (ব্রাউজারে, ~১০ হাজার রিকোয়েস্ট/মাস ফ্রি)
- "এই স্ক্রিপ্টটা রান করে আউটপুট দেখাও" → আসল আউটপুট → পরের ধাপে বাগফিক্স
- ক্যানভাস/কোড ওয়ার্কস্পেস বাটন তখনই আনব (আজ hide — সঠিক সিদ্ধান্ত)

### B4. Agent নিরাপত্তা
- প্রতিটি টুল-কলের আগে পারমিশন গেট (§26/§38/§39 নিয়ম) — ফাইল ডিলিট, পাবলিক পোস্ট, কস্ট>টাকার কাজে কনফার্ম
- লিমিট: প্রতি টাস্ক সর্বোচ্চ ৮টি টুল-কল, টাইমআউট ২ মিনিট, লুপ-ডিটেকশন

## ৪. Phase C — প্রোডাক্ট লেভেল (৩–৬ সপ্তাহ, $0–$১০/মাস)

### C1. অ্যাকাউন্ট + ডেটা আলাদাকরণ (সবচেয়ে জরুরি প্রোডাক্ট-গেট)
- GitHub OAuth লগইন (ফ্রি) বা ইমেল+পাসকোড (Cloudflare D1/Supabase ফ্রি)
- প্রতি-ইউজার KV key (`u:<id>:chats`) — আজকের পাবলিক অ্যানোনিমাস মডেল থেকেই সবচেয়ে বড় লাফ
- সেশন-টোকেন, রেট-লিমিট প্রতি-ইউজার

### C2. শেয়ার + আর্টিফ্যাক্ট
- চ্যাট শেয়ার লিংক (read-only), পাবলিক-অফ টগল, PDF এক্সপোর্ট
- "আর্টিফ্যাক্ট কনটেইনার": উত্তর থেকে টেবিল → চার্ট/ডায়াগ্রাম (ক্লায়েন্ট-সাইড, ফ্রি)

### C3. ড্যাশবোর্ড (রিয়েল ডেটা)
- /api/usage-এর ডেটা থেকে: মডেল-ওয়াইজ কস্ট/টোকেন, হারানো রিকোয়েস্ট, লেটেন্সি, provider হেলথ
- সিস্টেম স্ট্যাটাস / ডিপ্লয়মেন্ট সেকশন — **তখনই see হবে** যখন রিয়েল হয়ে যাবে (§45)

### C4. রিলায়েবিলিটি
- প্রথম-টোকেন টার্গেট <১ সেকেন্ড (Groq দ্রুত আছে — টিউনিং)
- provider ফেইল → অটো-ফলব্যাক (আছে) + "আমরা জানি, কাজ চলছে" মেসেজ
- ক্যাশ: একই প্রশ্নের উত্তর KV-তে (১৫ মিনিট) — খরচ কমায়

## ৫. Phase D — সত্যিকারের "Gemini লেভেল" (বাজেট লাগবে — সৎ কথা)

| ফিচার | খরচ (আনুমানিক) | নোট |

| জেমিনি ৩ প্রো / GPT-ক্লাস মডেল ফলব্যাক | ~$১০–২০/মাস | ফ্রি টিয়ার রেট-লিমিটেড, ফলব্যাক হিসেবে দারুণ |
| ইমেজ জেনারেশন (ওপেন-সোর্স self-host-ও পারে) | ~$৫/মাস বা $0 (self-host GPU লাগবে) | ফ্রি API-তে ইমেজ জেন নেই — মিথ্যা দেখাবো না |
| রিয়েল-টাইম ভয়েস কথোপকথন (Gemini Live API) | ~$৫–১০/মাস | দুই পাশে TTS+STT রিয়েলটাইম |

**বাজেট ম্যাট্রিক্স (কোন লেভেলে কী পাওয়া যাবে):**
- **$0:** Phase A সম্পূর্ণ + B (রিসার্চ/ফাইল/কোড agent) + C (অ্যাকাউন্ট, শেয়ার, ড্যাশ) → ব্যবহারকারীর চোখে ChatGPT-এর ~৮০% অভিজ্ঞতা

- **~$৩০/মাস:** ইমেজ জেন + ভারী স্যান্ডবক্স + স্কেল → ~৯৮%+ (বাকি ২% = proprietary infra যেটা কেউ ক্লোন করতে পারে না)
