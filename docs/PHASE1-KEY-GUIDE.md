# PHASE 1 — মালিকের জন্য Key সংগ্রহ গাইড (A-to-Z)

> JUJU তৈরি করেছে — Temp Phase 1 (সেরা ২০ AI মডেল সংগ্রহ)।
> নিচের প্রতিটা সাইট থেকে key এনে আমাকে দিন — আমি সিস্টেমে বসিয়ে দেব (D1-এ নিরাপদে সংরক্ষণ, কোড v36-এ সব provider আগে থেকেই wired করা আছে)।

## যেগুলো আপনার কাছ থেকে দরকার (সহজ থেকে কঠিন)

### ১) NVIDIA NIM — ১০০০ ফ্রি ক্রেডিট, কার্ড লাগে না ⭐ সবার আগে এটা
1. যান: **https://build.nvidia.com**
2. ডানদিকে **Sign In** → **Continue with Google** (Gmail দিয়ে এক ক্লিকে)
3. লগইনের পরে ডান-উপরে আপনার আইকনে ক্লিক → **API Keys**
4. **Generate API Key** চাপুন → key কপি করুন (`nvapi-...` দিয়ে শুরু)
5. আমাকে পাঠান: `NVIDIA_API_KEY: nvapi-...`
- **কী পাবেন:** DeepSeek-R1, Kimi K2.5, Nemotron, Llama — সব এক key-তে
- **লিমিট:** ১০০০ ক্রেডিট, ৪০ রিকোয়েস্ট/মিনিট
- **কার্ড:** লাগবে না ✅

### ২) DeepSeek — খুব সস্তা + ফ্রি টোকেন
1. যান: **https://platform.deepseek.com**
2. **Sign Up** → Gmail বা ফোন নম্বর দিয়ে
3. লগইনের পরে বাঁয়ে **API Keys** মেনু → **Create new API key**
4. key কপি করুন (`sk-...` দিয়ে শুরু)
5. আমাকে পাঠান: `DEEPSEEK_API_KEY: sk-...`
- **কী পাবেন:** DeepSeek Chat (V3) — কোডিংয়ে দারুণ
- **লিমিট:** ফ্রি টোকেন অফার দেখালে সেটা অটো; না দেখালে মিনিমাম টপ-আপ (~$1-৫) লাগতে পারে — টপ-আপ করবেন কি না আমাকে জিজ্ঞেস করে সিদ্ধান্ত দিন
- **কার্ড:** টপ-আপের ক্ষেত্রে লাগতে পারে ⚠️

### ৩) xAI (Grok) — নতুন অ্যাকাউন্টে $25 ফ্রি ক্রেডিট
1. যান: **https://console.x.ai**
2. **Sign up** (পুরনো অ্যাকাউন্ট থাকলেও **নতুন Gmail** দিয়ে বানান — পুরনোটার ক্রেডিট শেষ)
3. ভেতরে ঢুকে **API Keys** → **Create API Key**
4. key কপি করুন (`xai-...` দিয়ে শুরু)
5. আমাকে পাঠান: `XAI_API_KEY: xai-...`
- **কী পাবেন:** Grok 4 Fast (২ মিলিয়ন কনটেক্সট!)
- **লিমিট:** $25 ফ্রি ক্রেডিট
- **কার্ড:** সাইনআপে লাগে না; ক্রেডিট শেষ হলে লাগে ⚠️
- **নোট:** আমার টেস্টে পুরনো key-তে "team has no credits" দেখাচ্ছে — নতুন অ্যাকাউন্টে সাইনআপের সময় ক্রেডিট অফার দেখাচ্ছে কি না খেয়াল করবেন; না দেখালে আমাকে বলবেন, বাদ দেব

### ৪) Mistral (আবার দেখা — ৩০ সেকেন্ডের কাজ, ইচ্ছা হলে)
- আমাদের key আছে, শুধু রেট-লিমিটে ঠেকছে। নতুন key নিতে চাইলে:
1. যান: **https://console.mistral.ai** → Gmail দিয়ে লগইন
2. **API Keys** → **Create new key**
3. আমাকে পাঠান: `MISTRAL_API_KEY: mistral-...`

### ৫) Cerebras (চেক করুন — ইচ্ছা হলে)
1. যান: **https://cloud.cerebras.ai** → লগইন → **Billing** ট্যাব
2. দেখুন ফ্রি টিয়ার চালু আছে কি না। নতুন key নিতে: **API Keys** → Create
3. আমাকে পাঠান: `CEREBRAS_API_KEY: csk-...`
- **বাস্তবতা:** এখন 402 দিচ্ছে — ফ্রি টিয়ার হয়তো নীতি বদলেছে; কাজ না করলে বাদ দেব (CF Workers AI তো একই GPT-OSS-120B ফ্রি দিচ্ছে ✅)

## Key দিলে আমি কী করব (আপনার কিছু করতে হবে না)
1. Key D1 ডেটাবেজে `cfg:<নাম>` হিসেবে লিখব (সার্ভার-সাইড, ইউজার কখনো দেখে না) — GITHUB_PAT আপডেটে এই পথ আজই টেস্ট করা ✅
2. Worker v36-এ সব provider আগে থেকে wired: KEYMAP + endpoint + মডেল-লিস্ট + বেঞ্চ
3. ছোট একটা রিফ্রেশ-ডিপ্লয় দেব (key ক্যাশ রিসেটের জন্য)
4. `/api/system` বেঞ্চে ALIVE দেখিয়ে রিপোর্ট দেব

## নিরাপত্তা নোট
- Key শুধু D1-এ যায় (Cloudflare, আমাদের নিজের ডেটাবেজ) — repo PUBLIC, তাই কোথাও key লেখা হয় না
- চ্যাটে key পাঠালে সেটা JUJU-MEMORY/repo-তে কখনো লিখব না — শুধু `cfg:` D1-তে
- কোনো key লিক করলে ওই সাইটে গিয়ে key delete/revoke করে দিলেই নিরাপদ
