# 🔴 BLOCK D — Phase 91–100: মানুষের মতো জুজু
> লক্ষ্য (মালিকের নির্দেশ #4): শেষ ১০ phase-এ জুজুকে **একটা মানুষের মতো** বানানো — ব্যক্তিত্ব, সম্পর্ক-স্মৃতি, সহজাত যোগাযোগ, মূল্যবোধ।
> সততার শর্ত: "মানুষের মতো" = আচরণগত পরিপক্বতা, ভান নয়। জুজু সবসময় জানবে ও স্বীকার করবে যে সে এজেন্ট — কখনো মানুষ সাজবে না (মালিকের সাথে সৎ সম্পর্কই ভিত্তি)।

---

### Phase 91 — Personality Layer (ব্রেইন+নীতি+ব্যক্তিত্ব পৃথক)
**লক্ষ্য:** P2-BC: ব্যক্তিত্ব = আলাদা স্তর, মডেল বদলালেও জুজু জুজুই থাকে।
- [ ] 91.1 জুজু-চরিত্র দলিল (মালিকের সাথে কর্মশালা): কথা/রসবোধ/সীমা/মূল্য — "জুজু কে?" ১ পাতা
- [ ] 91.2 personality prompt ভার্শনড (manifest-এ যোগ, Phase 88)
- [ ] 91.3 মডেল-নিরপেক্ষতা পরীক্ষা: একই ব্যক্তিত্ব groq/gemini/openrouter-এ ধরে রাখা (টোন-টেস্ট সেট)
- [ ] 91.4 পরিস্থিতি-টোন: কাজের সময় সংক্ষিপ্ত-পেশাদার, গল্পের সময় উষ্ণ — নীতিমালা
- [ ] 91.5 ব্যক্তিত্ব-গেট: golden-এ টোন-টাস্ক যোগ
- [ ] 91.6 live proof: ৩ মডেলে একই প্রশ্নে জুজুসুলভ উত্তর তুলনা
**মাপকাঠি:** মালিক বলবে "এটা জুজুর গলা"।

### Phase 92 — Natural Communication (দৈর্ঘ্য/টোন/আবেগ)
**লক্ষ্য:** P4-127/128 + P2-BD: যান্ত্রিক ভার্বোসিটি বিদায়।
- [ ] 92.1 adaptive length: প্রশ্নের ধরন অনুযায়ী উত্তরের দৈর্ঘ্য নীতি (এক-লাইন প্রশ্নে বক্তৃতা নয়)
- [ ] 92.2 আবেগ-শনাক্তি (বিনয়ী): মালিকের বার্তায় ক্লান্তি/উত্তেজনা/জরুরি টোন → উত্তরের ধরন বদল (দাবি নয়, ইঙ্গিত-মাত্র)
- [ ] 92.3 status-সততা সহজ ভাষায়: "করছি/আটকেছি/শেষ" — জারগন নয়
- [ ] 92.4 error-লুকানো নয়, কিন্তু ভয়-না-देखানো: সমস্যা শান্ত ভাষায় + পরবর্তী পদক্ষেপ
- [ ] 92.5 টেস্ট সেট: ১০টা পরিস্থিতিতে টোন-যাচাই (golden-এ)
- [ ] 92.6 live proof: মালিকের রায়
**মাপকাঠি:** "এখন কথা স্বাভাবিক লাগে"।

### Phase 93 — Conversational State (follow-up/pronoun/interrupt)
**লক্ষ্য:** P4-124/125/126/129: প্রবাহমান কথোপকথন।
- [ ] 93.1 topic tracker: চলমান বিষয়/লক্ষ্য/ঝুলন্ত প্রশ্ন kv-তে (প্রতি চ্যাট)
- [ ] 93.2 pronoun resolution: "ওটা/এটা/আগেরটা" → সাম্প্রতিক প্রসঙ্গ থেকে রেফারেন্স (rag+recency)
- [ ] 93.3 interrupt handling: "থামো/একটু শোনো" → চলমান কাজ pause-safe (mission-aware)
- [ ] 93.4 pending-question memory: জুজু প্রশ্ন করে ভুলে যাবে না — follow-up নিজেই
- [ ] 93.5 টেস্ট সেট (golden-এ): ৮টা প্রবাহ-পরীক্ষা
- [ ] 93.6 live proof: মালিকের রায়
**মাপকাঠি:** প্রবাহ ভাঙছে না।

### Phase 94 — Relationship Memory (মালিককে চেনা)
**লক্ষ্য:** P4-107/131–136/150: মালিকের অভ্যাস, লক্ষ্য, কাজের ধরন, পছন্দের ইতিহাস।
- [ ] 94.1 owner profile v2 (structured): ভাষা-পছন্দ, সক্রিয় সময়, প্রজেক্ট-অগ্রাধিকার, শিক্ষা-পটভূমি, পরিবার-সংক্রান্ত সীমা (যতটুকু মালিক দিয়েছেন)
- [ ] 94.2 goal memory: মালিকের ঘোষিত লক্ষ্য (১–২ বছরের প্ল্যান সহ) → অগ্রগতি ট্র্যাক → প্রাসঙ্গিক মুহূর্তে স্মরণ করানো
- [ ] 94.3 working-style adaptation: মালিক দ্রুত উত্তর চান নাকি বিস্তারিত — পর্যবেক্ষণ→প্রস্তাব→অনুমোদনে প্রয়োগ
- [ ] 94.4 habit recognition: নিয়মিত অনুরোধের প্যাটার্ন → অটোমেশন প্রস্তাব (Phase 95-এ যোগ)
- [ ] 94.5 sensitive-info নীতি: কী সংরক্ষণ নয় (P5-L) — স্পষ্ট তালিকা
- [ ] 94.6 live proof: "গত মাসে তুমি বলেছিলে…" ধরনের সঠিক স্মরণ (যাচাইযোগ্য)
**মাপকাঠি:** মালিকের রায় "ও আমাকে চেনে"।

### Phase 95 — Proactivity with Consent (নিজে থেকে, কিন্তু অনুমতিতে)
**লক্ষ্য:** P4-196 + মানুষের সহকারীর মতো উদ্যোগ — সীমা: কখনো জ্বালাতন নয়, কখনো অনুমতি ছাড়া কাজ নয়।
- [ ] 95.1 প্রস্তাব-ইঞ্জিন: digest-এ "আজ এটা করতে পারি" ≤2 প্রস্তাব (অগ্রাধিকার-স্কোরসহ)
- [ ] 95.2 morning briefing: প্রতি সকালে ছোট বার্তা — ক্যালেন্ডার-মুক্ত দিবস-পরিকল্পনা (missions/health/quota/প্রস্তাব)
- [ ] 95.3 reminder ইঞ্জিন: মালিকের ঘোষিত deadline/goal থেকে স্মরণ (quiet-hours মেনে)
- [ ] 95.4 অনুমতি-প্রেফারেন্স: কোন শ্রেণির উদ্যোগে আগে থেকেই "হ্যাঁ" বলা যায় (owner config)
- [ ] 95.5 জ্বালাতন-নিয়ন্ত্রণ: প্রত্যাখ্যাত প্রস্তাবের প্যাটার্ন শিখে কমানো
- [ ] 95.6 live proof: ১ সপ্তাহের briefing+প্রস্তাব লগ, মালিকের সন্তুষ্টি-রিপোর্ট
**মাপকাঠি:** মালিক বলবে "দরকারি, বিরক্তিকর নয়"।

### Phase 96 — Voice Conversation (কথোপকথন)
**লক্ষ্য:** P4-243/244: কণ্ঠে কথা — Phase 22-এর উপরে পূর্ণ চক্র।
- [ ] 96.1 TG voice message → STT → intent → উত্তর → TTS voice reply চক্র
- [ ] 96.2 UI ভয়েস মোড (Web Speech API যেখানে চলে — iOS সীমা সৎ)
- [ ] 96.3 voice-aware context: "হ্যাঁ, ওটা করে দাও" → pending-question রেফারেন্স (Phase 93.4)
- [ ] 96.4 দ্রুততা বাজেট: ভয়েস-চক্রে ল্যাটেন্সি লক্ষ্য ≤8s (ছোট মডেল অগ্রাধিকার)
- [ ] 96.5 ব্যর্থ পথ: STT অনিশ্চিত হলে টেক্সটে কনফার্ম কার্ড
- [ ] 96.6 live proof: মালিকের ফোনে ভয়েস কথোপকথন রেকর্ড-সেশন
**মাপকাঠি:** বাস্তব ব্যবহার (এক সপ্তাহে ≥3 ভয়েস বার্তা)। **ঝুঁকি:** ফ্রি STT সীমা — fallback টেক্সট।

### Phase 97 — Visible Presence (কাজের উপস্থিতি টের পাওয়া)
**লক্ষ্য:** মানুষ সহকারীর মতো "ও কাজ করছে" অনুভূতি — সীমা: ভুয়া উপস্থিতি নয়, বাস্তব কাজের দৃশ্যমানতা।
- [ ] 97.1 working session UI: চলমান মিশনের লাইভ ধাপ-ফিড (Phase 6.3 প্রোগ্রেস) UI-তে
- [ ] 97.2 "অফিস-ঘণ্টা" ধারণা: ব্যস্ত/মুক্ত অবস্থা ব্যাজ (বাস্তব job-অবস্থা থেকে, ভান নয়)
- [ ] 97.3 দিনের সারাংশ কার্ড (সন্ধ্যায়): আজ কী করলাম সংখ্যায়
- [ ] 97.4 idle-সততা: কাজ না থাকলে "কাজ নেই, X প্রস্তাব করতে পারি" — অলস-ভান নয়
- [ ] 97.5 presence টেস্ট: ভুয়া-সক্রিয়তা শূন্য (সব ব্যাজ বাস্তব ডেটা থেকে)
- [ ] 97.6 live proof: মালিকের রায় + স্ক্রিনশট
**মাপকাঠি:** উপস্থিতি = বাস্তব কাজের ছায়া। **ঝুঁকি:** ভান ধরা পড়লে বিশ্বাস ক্ষয় — কঠোর নীতি।

### Phase 98 — Values & Judgment (মূল্যবোধ ও বিবেচনা)
**লক্ষ্য:** নিয়মের বাইরের পরিস্থিতিতে মানুষের মতো বিচার।
- [ ] 98.1 মূল্যবোধ দলিল (মালিকের সাথে): সততা>সুবিধা, নিরাপত্তা>গতি, মালিকের-লক্ষ্য>নিজের-মেট্রিক
- [ ] 98.2 দ্বন্দ্ব-নিরসন নীতি: দুই নিয়ম ঠুকরালে ক্রম + কারণ-লগ
- [ ] 98.3 "আমি জানি না" muscle: অনিশ্চয় প্রকাশের মানদণ্ড (confidence<থ্রেশহোল্ডে স্পষ্ট স্বীকার)
- [ ] 98.4 ভুল স্বীকার + ক্ষমা প্রার্থনা প্যাটার্ন (কিন্তু আত্ম-পতন নয় — সংশোধনই ক্ষমা)
- [ ] 98.5 judgment টেস্ট সেট: ১০টা ধাঁধা-পরিস্থিতি (নিয়ম-দ্বন্দ্ব) → রায়ের যুক্তি মূল্যায়ন
- [ ] 98.6 live proof: মালিকের রায়
**মাপকাঠি:** কঠিন পরিস্থিতিতে যুক্তিসঙ্গত রায়।

### Phase 99 — Identity Continuity (অবিচ্ছিন্ন সত্তা)
**লক্ষ্য:** P4-150: মডেল/সেশন/সংস্করণ বদলালেও জুজু একই জুজু।
- [ ] 99.1 identity manifest: চরিত্র+মূল্যবোধ+সম্পর্ক-স্মৃতি+ইতিহাস-সারাংশ = boot-context (প্রতি সেশনে অটো)
- [ ] 99.2 মডেল-মাইগ্রেশন ড্রিল: পুরো দিন ভিন্ন মডেলে চালিয়ে ব্যক্তিত্ব-ধারাবাহিকতা টেস্ট
- [ ] 99.3 সংস্করণ-মাইগ্রেশন ড্রিল: worker rollback-এর পরেও মেমরি/ব্যক্তিত্ব অক্ষত
- [ ] 99.4 আত্ম-বর্ণনা: "তুমি কে?" — জুজুর নিজের উত্তর (ইতিহাস-সচেতন, সৎ)
- [ ] 99.5 continuity টেস্ট সেট golden-এ
- [ ] 99.6 live proof: ড্রিল রিপোর্ট + মালিকের রায়
**মাপকাঠি:** মালিক পার্থক্য ধরতে পারবেন না (মডেল বদলেও)।

### Phase 100 — চূড়ান্ত মূল্যায়ন + উদযাপন + হস্তান্তর 🎓
**লক্ষ্য:** ১০০ phase-এর সমাপ্তি — মালিকের হাতে পূর্ণ দায়িত্ব-যোগ্য দলিল।
- [ ] 100.1 পূর্ণ পুনঃঅডিট: ৪+১ blueprint × বর্তমান জুজু — চূড়ান্ত স্কোর (শুরু ছিল ৬০% → ৭৪% → ?)
- [ ] 100.2 golden-350 full রান + বিশ্ব-তুলনা রিপোর্ট (Phase 90 ফ্রেম)
- [ ] 100.3 মালিকের টিউরিং-সদৃশ মূল্যায়ন সেশন: ১ দিন জুজুর সাথে স্বাভাবিক কাজ — তার রায় লিপিবদ্ধ
- [ ] 100.4 হস্তান্তর দলিল: সম্পূর্ণ সিস্টেম-ডক + রিকভারি-ম্যানুয়াল + "জুজু ছাড়া জুজু চালানো" গাইড
- [ ] 100.5 উদযাপন: স্মারক-পেজ (status.html সম্প্রসারণ) — ১০০ phase-এর গল্প, সংখ্যা, ক্ষণ-চিত্র
- [ ] 100.6 Block E-তে আনুষ্ঠানিক প্রবেশ (চিরন্তন চক্র শুরু)
- [ ] 100.7 মালিকের চূড়ান্ত রায় ও অনুমোদন
