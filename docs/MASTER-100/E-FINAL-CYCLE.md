> মালিকের নির্দেশ #5: **"ফাইনাল টেস্ট গবেষণা improvement এগুলো নিয়ে ৩–৪ মাস কাজ করা।"**

- [ ] FINAL-AUDIT Block A/B/C/D সব লেখা

## E2. প্রস্থান-মানদণ্ড (Exit Criteria) — ৩–৪ মাস পরে সমাপ্তি ঘোষণা
- [ ] **নির্ভরযোগ্যতা:** ৯০ দিনে অপরিকল্পিত downtime ≤ ৩ ঘটনা, প্রতিটির post-mortem + প্রতিকার সম্পন্ন
- [ ] **গুণমান:** golden-350 স্কোর প্রবেশ-মুহূর্তের চেয়ে ≥১০ পয়েন্ট বেড়েছে (suite-version স্থির রেখে)
- [ ] **স্বয়ংসম্পূর্ণতা:** শেষ ৩০ দিনে অন্তত ২০টা মিশন সম্পূর্ণ, মানুষের হস্তক্ষেপ গড়ে ≤১ বার/মিশন (অনুমোদন বাদে)
- [ ] **প্রত্যাহার-ক্ষমতা:** rollback ড্রিল মাসিক সফল (কোনো ডেটা হারায়নি)
- [ ] **গবেষণা:** ≥৬টা গবেষণা প্রতিবেদন (মালিকের পছন্দের বিষয়) মান-গেট পাস
- [ ] **মালিকের সন্তুষ্টি:** লিখিত রায় + ব্যবহার-পরিসংখ্যান (প্রকৃত ব্যবহারের প্রমাণ)

## E3. দৈনিক চক্র (প্রতিদিন, heartbeat/watchman-এ অটো)

## E4. সাপ্তাহিক চক্র (প্রতি সপ্তাহে, মালিকের অনুমোদন-ছন্দে)

5. **memory hygiene** (Phase 78): dedupe/decay/conflict রিপোর্ট
6. **১টা improvement মিশন**: সপ্তাহের শীর্ষ সমস্যা সমাধানে (মালিক-অনুমোদনে)

## E5. মাসিক চক্র (প্রতি মাসে)
1. **full eval** (golden-350) + সংস্করণ-তুলনা চার্ট
2. **blueprint re-audit**: DEEP-RESEARCH গ্যাপ-তালিকার হালনাগাদ (কতগুলো বন্ধ হলো)
3. **গবেষণা সপ্রিন্ট**: ১–২টা গভীর গবেষণা (Phase 46/47 পাইপলাইনে) → PDF প্রতিবেদন মালিককে
4. **experimental phase**: ১টা পরীক্ষামূলক ক্ষমতা (প্ল্যানের বাইরে, সীমিত ঝুঁকিতে) → সফল হলে প্ল্যানে যোগ, না হলে শিখে বাদ
5. **নিরাপত্তা মাসিক**: red-team suite (Phase 89) + secret sweep + dependency audit
6. **খরচ-অডিট**: quota/টোকেন রিপোর্ট + economy টিউনিং (Phase 14)
7. **ডক রিফ্রেশ**: AGENTS.md/F-ONBOARDING/status হালনাগাদ (বাসি ডক = বাগ)

## E6. ত্রৈমাসিক চক্র (৩ মাস অন্তর)
